# Out of Tokens, Mid-Sentence

A make.fun entry for the [Out of Tokens, Mid-Sentence](https://make.fun/bounty/u-kiencx-out-of-tokens-mid-sentence-00f60233) competition.

The program writes one funny line to `/output/entry.txt`: the error message an AI agent shows when it runs out of tokens mid-sentence. The sentence died of token exhaustion, survived by three unfinished clauses and a semicolon.
